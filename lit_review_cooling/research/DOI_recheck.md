# DOI 二次核验（独立 WebSearch 复核）

核验日期：2026-11-01
方法：本会话中 doi.org / Crossref / OpenAlex / PubMed 直连及 WebFetch 均被阻断，Consensus 配额耗尽，故仅使用 `WebSearch`（标准模式为主，结果稀薄时用扩展模式）。对每个 DOI 先搜 DOI 字符串，再搜「作者 + 题名 + DOI 片段」；只有当出版商 / 机构库 / PubMed / Semantic Scholar / ResearchGate / OUCI / Scilit / RePEc 等页面在搜索结果中同时显示该 DOI 与该题名时，才记为 CONFIRMED。未在任何页面见到 DOI 字符串者，即使题名与出处相符，也不记为 CONFIRMED。

判定说明：
- **CONFIRMED** = 搜索结果页面同时显示该 DOI 与该题名（或 URL 本身含该 DOI 且页面题名相符）
- **MISMATCH** = DOI 指向其他论文 / 原记录的作者、刊名或 DOI 有误；备注给出正确信息
- **UNRESOLVED** = 无法在可访问页面上找到 DOI 与题名的对应关系
