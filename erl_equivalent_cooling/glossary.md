# Glossary (authoritative terms for this paper)

| Preferred term | Avoid | Definition / note | Abbreviation (define at first use) |
|---|---|---|---|
| air conditioning | AC (in prose), air-conditioner | vapour-compression cooling that holds a setpoint | AC allowed in tables and equations only |
| electric fan | fans (generic), ceiling fan unless meant | pedestal or ceiling fan producing elevated air speed at the occupant | |
| direct evaporative cooler | swamp cooler, desert cooler, air cooler | device that cools supply air adiabatically by evaporating water | DEC |
| equivalent temperature reduction | cooling effect, equivalent cooling (except in title) | dry-bulb reduction at still air and outdoor humidity that gives the same SET as the intervention state | ΔT |
| operating window | safety envelope (only when citing Morris 2021), operating conditions | set of outdoor (temperature, humidity) states in which a technology is assumed to run | |
| Standard Effective Temperature | SET* , standard effective temp | Gagge two-node index, ASHRAE 55 | SET |
| exposure temperature | effective exposure, felt temperature | temperature entering the exposure–response function | T_exp |
| exposure degree-hours removed | cooling degree-hours (reserve for AC energy), degree hours | Σ over hours of ΔT inside the window, K h | |
| equivalence ratio | relative effectiveness | exposure degree-hours removed by a technology divided by those removed by air conditioning under the same rule | |
| Default rule | default scenario | air conditioning operates above 23 °C and holds 23 °C, 55 % RH | |
| DLS rule | DLS scenario | air conditioning operates above 26 °C and holds 26 °C, 60 % RH (decent living standards) | DLS |
| saturation effectiveness | efficiency, pad efficiency | ε = (T_db − T_supply)/(T_db − T_wb) | ε |
| wet-bulb depression | | T_db − T_wb | |
| relative humidity | RH% | | RH |
| fan plus air conditioning | hybrid, fan-first (only when citing) | fan runs inside its window and the air-conditioning threshold is raised by 3 K | |
| ERA5 | ERA-5 | ECMWF fifth-generation reanalysis, hourly, 2020 | |
| exposure–response function | dose–response, temperature–mortality curve | relation between T_exp and a health outcome, here left generic | ERF (avoid, write in full) |

Units: °C for temperatures, K for differences and ΔT, m/s for air speed, % for RH, K h for degree-hours. Write "2 m/s" not "2 m s⁻¹".
