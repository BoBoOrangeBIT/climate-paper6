# prompt_defects.md — GLACE_NGA v1.0, run NGA_split_20260827

Situations the four prompt documents do not cover, recorded per Part 3 §4.2 ("Do not resolve an uncovered case by improvising a rule"). None were resolved by improvisation.

1. **No branch for a runner environment without web egress.** The prompts assume Claude in Chrome with ordinary consumer network access. A managed runner whose organisation egress policy denies all general HTTPS (this run) is not covered: gap codes C and C-geo are field-level, `stop_reason` has no value for a pre-frame block, and Checkpoint 0 cannot be emitted in the required form. Suggested addition: a Step 0 environment gate ("verify that PLATFORM_1, PLATFORM_2 and every Part 4 tier source answer over the runner's network **before** starting the run; on failure emit stop_reason=platform_blocked and the reachability table") plus an approved `stop_reason` value for it.
2. **Gap-code storage convention.** "Every blank field carries a gap code" (Part 2 §5) but no column layout for gap codes is defined anywhere in the field list. Decide: per-field companion columns vs. one `gap_codes` map column.
3. **robots.txt unverifiable is unhandled.** Compliance requires respecting robots.txt, but the prompts do not say what to do when robots.txt itself cannot be retrieved. This run treated it as blocking (no extraction without verified permission), which the template owner should ratify.
4. **Token accounting.** "Record token consumption as you go" is not implementable in runtimes that expose no counter; §4.1's "estimate marked estimated" was used, but a standard estimation basis (e.g. characters/4) would make estimates comparable across cells.
5. **Checkpoint delegation.** The prompts require written human approval at Checkpoints 0/0b/1 but do not define whether the human may pre-delegate approvals (as the operator did for this run). Define an explicit delegation form, including which checkpoints are delegable (recommendation: Checkpoint 0 is not, since it exists precisely to catch a wrong-platform error the pipeline cannot see).
